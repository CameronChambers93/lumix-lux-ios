# Lumix Lux for iOS

The iOS app for copying photos and videos off a Panasonic Lumix over Wi-Fi: the same page and camera drivers as the
[Android app](https://github.com/CameronChambers93/lumix-lux-android), with a Swift native plugin. **Not built yet**; the plan
is phase 7 of [lumix-lux-core](https://github.com/CameronChambers93/lumix-lux-core) `docs/REDESIGN.md` (section 4: iOS notes).

```sh
git clone --recurse-submodules https://github.com/CameronChambers93/lumix-lux-ios.git
```
